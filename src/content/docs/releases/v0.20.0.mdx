**Released: September 7, 2026**

### Features

- Ricochet now supports the [`_server.yml`](https://posit-dev.github.io/plumber2/articles/server_yml.html) standard, so you can deploy [`{plumber2}`](https://posit-dev.github.io/plumber2), [`{fiery}`](https://fiery.data-imaginist.com/), and [`{mcptools}`](https://posit-dev.github.io/mcptools/) configs.

### Improvements

#### User Interface

- You can now edit settings rows in place, without going to a separate page.
- Active tabs show an underline to make navigation clearer.
- The UI now reports lockfile mismatches in more detail.

### Fixes

#### Kubernetes

- Service ports no longer change when an app restarts.
- Version check jobs now wait on the correct scoped name, so they no longer time out early.
- Execution environment checks now finish after an interruption.

#### General

- Viewing deployment logs no longer crashes the app.
- Package environments now rebuild on their own when the execution environment changes, so they stay consistent.
