**Released: August 14, 2026**

### Features

#### Deployments

- Create new deployments from Git repositories through the REST API.
- Fetch and update deployment environment variables through the REST API.

#### Authentication

- Switch between authenticated SSO accounts without signing out first.
- Retrieve the current user's stored Git credentials through the REST API.

#### UI

- Ricochet now sets the UI timezone from your browser.

### Fixes

#### Deployments

- Apps with a minimum instance count now restart on their own when workers stop.
- Ricochet now records why a worker stopped and shows you the reason.
- Rootless container-in-container deployments now resolve subordinate user and group IDs correctly.

#### UI

- Environment variable names and values are now capped at the size encryption supports, which blocks invalid input.
- File uploads provide clearer progress and feedback.

#### Core

- Read-only commands no longer set up a new Ricochet instance by surprise.
- Ricochet resolves its home and content directories consistently across commands.

#### API

- API errors now show their real details instead of placeholder text.
