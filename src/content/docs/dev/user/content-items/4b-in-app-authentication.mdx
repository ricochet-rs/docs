---
title: In-App Authentication
---

Because ricochet uses your own identity provider, it can be integrated within your own applications.
This page documents how to login and logout of the identity provider from an app.
To understand how to detect the signed in user see [Detecting the Current User](/dev/user/content-items/4-detecting-current-user/).

Ricochet reserves the `/signin` path for each application to be used to integrate with your identity provider.
The `/signin` path provides an optional `?next=` query parameter which defines where to navigate after a successful sign in.

Use this, with the `RICOCHET_APP_PATH` environment variable which provides the full path of the application on the server (e.g. `/app/{slug-or-content-id}`).
Additionally, the `RICOCHET_URL` environment variable can be used for a complete authentication flow inside of your own apps.
Additionally, the `/logout` path can be used to sign users out as well.
