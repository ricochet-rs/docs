**Released: October 7, 2026**

## Features

### Task

- `ricochet task run` now waits for task completion when you pass `--wait` instead of returning immediately after submission.

### Deploy

- `ricochet deploy` command now supports `-dry-run` to preview bundle contents before deployment.
- Deployment output now includes the names of deployed apps and tasks for easier identification.

### Login

- `ricochet login` command now supports `--no-browser` for authentication in remote or headless sessions.

### General

- Jupyter notebooks are now supported.

## Bug Fixes

### Config

- The `RICOCHET_API_KEY` environment variable is now applied to API requests when the target URL has no configured credentials.
