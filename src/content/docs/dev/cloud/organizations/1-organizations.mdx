An organization owns instances, members, and billing.
Any signed-in user can create one, and the creator becomes its owner.

## Create an organization

<Steps>

1. Select **Organizations** in the sidebar, then **Create organization**.

2. Enter a display name.

3. Accept the suggested slug or type your own.

    A slug is lowercase letters, numbers, and single hyphens, for example `acme-corp`.
    It must be unique across Ricochet Cloud.

</Steps>

A new organization starts on a [trial](/dev/cloud/billing/1-subscription/), so you can create an instance before setting billing up.

## Why the slug matters

The slug is part of every instance hostname.
An instance called `prod` in the organization `acme-corp` answers at `prod-acme-corp.cloud.ricochet.rs`.

You can rename an organization at any time.
**You cannot change its slug while it still has instances.**

## Delete an organization

Deleting is owner-only and permanent.
It removes the organization, its instances, and the data on them.

Two things block a deletion:

- A live subscription.
- An instance that could not be torn down.

You must type the organization's slug to confirm.
