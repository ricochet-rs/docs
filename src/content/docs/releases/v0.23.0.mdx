**Released: September 21, 2026**

### Features

#### Authentication
- Connect native SAML identity providers for single sign-on.

#### Administration
- Administrators can lock or delete user accounts from the admin panel.
- Configure restore concurrency on a per-instance basis to control parallel restore operations.

### Fixes

#### Proxy
- Julia environments now precompile successfully and no longer recompile the standard library on each session start.
- Backend delegation no longer incorrectly counts referer requests toward routing decisions.
- Supervisor logs no longer emit a line per instrumented call on every tick, reducing log volume.

#### User Interface
- The user profile page displays an improved header, content list, and empty state.
- The mobile sidebar now closes automatically when you navigate to a new page.
- Hydration errors no longer occur during development with Leptos.
- The log view folds the log list and aligns renv output for easier reading.

#### Data and Restore
- The first-user database probe now casts to bigint, preventing type mismatch errors.
- The renv source cache remains inside the pod during restore operations, ensuring package availability.
