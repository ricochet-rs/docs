**Released: November 2, 2026**

### Features

- Added email notification support
  - Failure notifications are sent for failed deployments and task runs.
  - On successful task runs custom emails can be delivered with attachments up to 20mb.
  - Email bodies can be customized using markdown.
  - A new API scope for account settings was added to control user-level email preferences.
  - Configure your email provider via the `[smtp]` configuration, see the [docs](/dev/admin/configuration/email/).
- Added secret store integrations for HashiCorp Vault and Azure Key Vault.
- An MCP server is added to the ricochet REST API at `/api/v0/mcp`
  - The MCP server can list content items, deployments, view logs, and view settings.
- Added the `genie` content type for Genie.jl apps.
- Added the `python-app` content type for Python web apps such as Panel.
- Task runs now have a configurable maximum duration, which defaults to one hour.

### Enhancements

- Environment variable values are no longer limited to 190 bytes.
- A deployment's restore state and logs are now available from the API.
- The metrics address is now configurable.
- Added a build info metric that includes the running version.
- On Kubernetes, resource changes are now applied without restarting the app, and new instances are ready sooner.

### UI

- Redesigned the deployment history table.
- Server settings are now organized into tabs.
- Item tabs are now hidden based on the user's role.
- Breadcrumbs now appear on narrow screens.

### Bug fixes

- Resolved several security issues.
- Resolved a bug where Authorization headers were stripped unconditionally.
- Resolved a bug where idle WebSocket connections closed before the app's inactivity timeout.
- Resolved a bug where an expired session caused an error instead of signing the user out.
- Resolved a bug where a broken app restarted in a loop.
- Resolved bugs where Shiny apps with a root-level `server.R`, plumber2 apps that use absolute paths, and Genie apps failed to start.
- Resolved a bug where deployments were marked out-of-sync incorrectly.
- Improved the reliability of R, Julia, and Python package installs.
- Resolved a bug where memory limits were not always enforced.
- A slug that matches another item's ID is now rejected.
- Sign-in errors now include the reason the identity provider rejected the sign-in.
