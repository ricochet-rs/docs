**Released: November 18, 2026**

## Features

- `ricochet mcp` lets AI assistants deploy and manage your Ricochet content through the Model Context Protocol.
- `ricochet lsp` shows `_ricochet.toml` errors in your editor as you type, in any editor that supports the Language Server Protocol.

## Bug fixes

- `ricochet deploy` checks the form of a Git repository URL and accepts URLs that point to a folder.
