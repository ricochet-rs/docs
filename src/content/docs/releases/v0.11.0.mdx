**Released: June 11, 2026**

### Features

- Admins can now see all deployments and rerun them from the UI.
- User avatars now sync from Microsoft Entra through the Graph API.
- The new `ricochet stop` command cleanly stops a daemonized Ricochet instance.

### Fixes

- All background proxy services now stop when they get a stop signal.
- User search and role filters now work in the admin UI.
- Client SSE disconnects no longer show up as proxy failures in the logs.
- The UI no longer panics at times when you move between pages.
- Ricochet restarts pods after a force-restore succeeds.
