**Released: September 17, 2026**

### Features

#### Database

- Database queries are faster.
- Avatar images now live in the database instead of on disk to support high availability.

#### Deployment

- Ricochet now removes app instances that run out of memory or die, so no traffic goes to dead processes.
- Queued deployments now survive restarts, and task runs now link to their logs.

### Enhancements

- The "Explore", "My Apps", and "My Tasks" list views have a new design that is easier to read.
- Leader election now supports multi-instance deployment.
### Fixes

#### Interface

- The Git deployment form now only shows visibility options your license allows.
- Deployment log streams now reconnect on their own and keep following running attempts past the idle timeout.

#### Deployment

- Restarting an app no longer triggers a rolling update if the deployment spec is unchanged.

#### API

- Every listed content item now includes the owner's identity in the response.
