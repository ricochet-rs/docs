**Released: September 2, 2026**

### Features
- Ricochet exposes Prometheus metrics with request information for tasks and apps at `/metrics` on port 6189, as the [docs](https://docs.ricochet.rs/v0-19/admin/technical/metrics/index.html) describe.

#### Explore page
- The explore page has been reworked to be easier to navigate.

#### Apps and tasks
- Copy the app URL directly from the overview page.
- Stop running tasks from the UI.
- In the community edition, apps and static sites now have a very small "powered-by" ricochet logo on the lower right hand side.

#### API and administration
- Server admins can now list all content items using a new "read" scope.

### Fixes

- Python execution-environment configurations now have an optional `uv` field for the path to the `uv` binary, which defaults to `/usr/lib/uv` to match the provided [exec-envs](https://github.com/ricochet-rs/exec-envs).
- Mobile layouts display content more consistently.
- When matching versions, a newer minor version is always used rather than the previous distance based metrics.
- Navigation quick links collapse properly and breadcrumbs no longer wrap unexpectedly.
