**Released: September 21, 2026**

### Features

#### Authentication
- Connect native SAML identity providers for single sign-on.

#### Administration
- Administrators can lock or delete user accounts from the admin panel.
- Set restore concurrency per instance to control how many restores run in parallel.

### Fixes

#### Proxy
- Julia environments now precompile without errors and no longer recompile the standard library at each session start.
- Backend delegation no longer counts referer requests when it picks a route.
- The Supervisor now writes far fewer routine messages, so they no longer flood the logs.

#### User Interface
- The user profile page has a better header, content list, and empty state.
- The mobile sidebar now closes when you go to a new page.
- Fixed UI hydration bugs that prevented navigation in the deployment history view.
- You can now collapse the deployment logs list.
