**Released: April 30, 2026**

### Fixes

- Upgrades now cope with database migrations that only partly ran, so updating Ricochet no longer fails.
- Ricochet no longer runs the migration step that broke database checksums between dev and release builds.
- renv restore now works in kubernetes and linux, since each one has its own restore command.
- Startup no longer waits for filesystem walks that gather environment info, since they now run in the background.
- A new unprefixed musl-g++ wrapper fixes build errors in same-architecture container builds.
