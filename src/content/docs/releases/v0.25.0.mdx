**Released: November 2, 2026**

### Features

- Get email notifications for your deployments and task runs.
  - Find out by email when a deployment or task run fails.
  - Email a custom message with up to 20 MiB of attachments after a task run succeeds.
  - Write your messages in Markdown.
  - Manage your email preferences through the API with the new account settings scope.
  - Configure your email provider in the [`[smtp]` section](/dev/admin/configuration/email/).
- Read your apps' and tasks' environment variables from HashiCorp Vault or Azure Key Vault.
- Connect your AI assistant to the new Ricochet Model Context Protocol (MCP) server at `/api/v0/mcp`.
  - Ask your assistant to list your content items and deployments, or read their logs and settings.
- Deploy Genie.jl apps with the new `genie` content type.
- Deploy Python web apps, such as Panel, with the new `python-app` content type.
- Admins can cap how long a task run lasts, and the default is one hour.

### Enhancements

- Store environment variable values longer than 190 bytes.
- Check a deployment's restore status and list its logs through the API.
- Admins can choose the metrics address and see the running version in the metrics.
- On Kubernetes, change an app's resources without restarting it, and get new instances up faster.

### UI

- Browse deployment history in a redesigned table.
- Find server settings grouped into tabs.
- See only the item tabs your role allows.
- Navigate with breadcrumbs on narrow screens.

### Bug fixes

- Upgrade soon to get several security fixes.
- Use your app's own `Authorization` header, such as a bearer token, behind Ricochet.
- Your users stay connected over idle WebSockets until your app's inactivity timeout.
- Sign in again after your session expires, instead of seeing an error.
- Ricochet no longer restarts a broken app in a loop.
- Deploy Shiny apps with a root-level `server.R`, plumber2 apps that use absolute paths, and Genie apps without startup errors.
- Deploy R, Julia, and Python content with fewer package install failures and no false out-of-sync errors.
- Ricochet now applies your memory limits to every app and task run.
- You can no longer give an item a slug that matches another item's ID.
- See why your identity provider rejected your sign-in.
