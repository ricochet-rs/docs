**Released: March 3, 2026**

### Features

- Ricochet now writes an audit log of security events for compliance and monitoring.
- New content types support Python frameworks.
- Logs now rotate on their own.
- Ricochet now sends traces and metrics through OpenTelemetry.
### Fixes

#### Authentication

- OAuth callback errors now send users back to the login page instead of raw 4xx error pages.
- The first user now gets the admin role by default.

#### Kubernetes

- Multi-arch clusters now work, and restore logs show up in real time.
