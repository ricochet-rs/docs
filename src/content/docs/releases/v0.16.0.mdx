**Released: August 4, 2026**

### Features

#### UI

- The navbar now links to the release notes and the issue tracker, so you can see what changed or report a problem without leaving ricochet.

### Fixes

#### Core

- ricochet now runs inside a rootless container.
- Tracing and logging now start as early as they can, so the logs catch failures that happen before ricochet is fully up.
- Content items are now deleted in a background task, so the UI shows the delete right away.

#### UI

- The "View live" action now shows only when a static site has rendered HTML, so the link no longer leads to a missing page.
- Disabled buttons now show tooltips that explain why the action is not available.

#### Tasks

- Tasks that have never deployed now show a clear error and a way to recover.

#### Misc

- Some exit codes no longer count as a successful run by mistake.
- Packages now list `newuidmap` as a required dependency, so installs without it no longer fail at runtime.
