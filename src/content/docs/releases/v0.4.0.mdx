**Released: March 18, 2026**

### Features

- Shiny Python is a new content type, and the old Shiny option is now Shiny (R) to tell the two apart.

### Fixes

- Plumber apps with no path set now route to `/__docs__/`.
- Ricochet now finds Python installs that UV does not manage.
- Admins can now demote other admins.
- Julia processes now set `DATADEPS_ALWAYS_ACCEPT=1` so they never wait at a prompt.
- OTLP tracing now shuts down cleanly.

### Improvements

- Apps load more smoothly with no duplicate backends, and Kubernetes deployments no longer leak memory.
