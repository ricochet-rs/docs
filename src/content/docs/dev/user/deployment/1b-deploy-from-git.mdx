Deploy an app or task directly from a public or private Git repository.
Ricochet fills in the settings from the repository's [`_ricochet.toml`](/dev/user/deployment/2-ricochet-toml/) when it has one.

## Add a credential for a private repository

Skip this section when deploying a public repository.

<Steps>

1. Open **Credentials** in ricochet.

2. Select **Git Credentials**, then select **Add Credential**.

3. Enter a unique **Name** and choose the credential **Type**:

    - Choose `ssh` and paste an **SSH Private Key** for an SSH repository URL.
    - Choose `https` and enter the **Username** and **Password or Token** supplied by your Git provider for an HTTPS repository URL.

4. Select **Add Credential**.

</Steps>

<Aside type="caution">
  Use a credential with read-only access to the repository whenever your Git provider supports it.
</Aside>

## Deploy the repository

<Steps>

1. Open **Deploy** in ricochet.

2. Enter the **Repository URL**.

3. Under **Credential**, keep **Public** for a public repository or choose the saved credential for a private repository.

4. Select the **Branch** to deploy.

5. If the project is in a subdirectory, enter its repository-relative **Path**.

6. Check the **Settings** loaded from `_ricochet.toml`, or fill them in if the repository has none:

    - **Name**, **Type**, and **Entrypoint**.
    - **Visibility**: **Private**, **Internal**, or **External**.
      **Private** needs a license.
    - **Serve as a static site** for a report or notebook that renders to HTML.

7. To install packages from somewhere other than the server defaults, open **Package repositories**.

8. Select **Deploy**.

</Steps>

A check mark appears in **Entrypoint** and **Packages file** when Ricochet finds them in the repository.
You can select **Deploy** once both are found.

If another app or task already uses the ID in `_ricochet.toml`, select **Use new ID** to deploy this one separately.

Ricochet clones the selected revision and opens the new item's overview, where you can monitor the deployment.
