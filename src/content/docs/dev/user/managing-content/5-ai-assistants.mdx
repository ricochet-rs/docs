---
title: AI Assistants
---

Connect Claude, ChatGPT, or another Model Context Protocol (MCP) client to ricochet so your assistant can list the items you can access.

```bash
claude mcp add --transport http ricochet https://ricochet.example.com/api/v0/mcp
```

Replace the host with your server's address.
On Ricochet Cloud, the host is your [instance's address](/dev/cloud/quickstart/), such as `prod-acme-corp.cloud.ricochet.rs`.
In Claude Code, run `/mcp`, select **ricochet**, and select **Authenticate**.

## Sign in

Your assistant opens ricochet in your browser.

1. Sign in if ricochet asks you to.
2. Check the app name and the address ricochet sends you back to.
3. Select **Allow**.

The assistant sees what you see: the items you own or collaborate on, with your role on each.
An admin can ask for every item on the server.
The connection lasts as long as the assistant uses it at least once every 30 days.

## Disconnect an app

1. Open **Profile** from the user menu.
2. Find the app under **Connected apps**.
3. Select **Disconnect**.

The app is signed out at once and must ask you again before it can use ricochet.

## Other clients

Point any client that signs in with OAuth at `/api/v0/mcp` on your server.

- In claude.ai and Claude Desktop, add a custom connector with the address and keep the default sign-in.
- In ChatGPT, add a connector with the address and choose OAuth.
- In Cursor, add the address to `mcp.json`:

```json
{
  "mcpServers": {
    "ricochet": {
      "url": "https://ricochet.example.com/api/v0/mcp"
    }
  }
}
```

## Use a key instead

A script or a client without browser sign-in can send an API key instead.

1. Open **Credentials** in the sidebar.
2. Select **Create API Key**.
3. Keep **List and read items** ticked under **API Key permissions**.

Send the key in the `Authorization` header:

```bash
claude mcp add --transport http ricochet https://ricochet.example.com/api/v0/mcp --header "Authorization: Key rico_..."
```

## When it fails

- "This app is not registered with this server": remove the connection in your assistant and add it again.
- "Invalid API key" or "Expired API key": create a new key.
- "This account is locked": ask an admin to restore your access.
- A key without **List and read items** is refused, so create one with it ticked.
