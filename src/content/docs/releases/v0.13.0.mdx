**Released: July 6, 2026**

### Security

- Thumbnail serving and tar unbundling no longer risk giving access to files a user should not see.
- Some API endpoints now check server roles correctly.
- OIDC redirect URIs are now checked to block redirect attacks.

### Features

- Ricochet now adds an `X-Ricochet-User` header with the user JWT for downstream services.
- You can now set a maximum bundle size.

### Fixes

- List view filters now stay set when you reload the page.
- Listing users on an instance now needs a logged in user.
- Instances that stop early are now pruned at once and get no more requests.
- Session affinity cookies now persist as they should.
- The download-log button is now in the log header, where it is easier to find.
