**Released: July 1, 2026**

### Breaking Changes

- CLI commands have a new, clearer layout, and `ricochet --help` lists them all.

### Features

- You can now set environment variables at deploy time with the `--env` flag to configure your apps.
- The `self update` command has a new `--dry-run` option that shows available updates without installing them.
- You can now update app and task settings from a `_ricochet.toml` file to simplify your deploy workflow.

### Fixes

- The CLI now works with the latest ricochet-core version and its recent API changes.
