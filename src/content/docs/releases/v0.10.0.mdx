**Released: June 8, 2026**

### Features

#### UI

- Pages cross-fade when you move between them, and the effect respects your accessibility settings.

#### Auth

- Global admins can override changes to collaborators to manage access.
- Ricochet syncs groups from Microsoft Graph over OIDC, so groups from Microsoft Entra ID work in ricochet.

#### Container backend

- The Docker backend is now called "container" and supports execution environments with bind mounts for more flexible deployments.

### Fixes

#### Auth

- OIDC group access works with Microsoft Entra, and its error messages are easier to diagnose.

#### UI

- Microsoft Edge no longer freezes on the app loading page.

#### Deployment

- You can cancel a running deployment as expected.
- Image aliases now reach execution environment validation as expected.

#### General

- Ricochet no longer tries to start when the API fails to connect, which prevents startup problems.
