---
title: Versions and Upgrades
---

Each instance either follows the fleet or stays on a version you pick.
Change this on the instance card, under **Version**, as an owner or admin.

## Dynamic versus static

**Dynamic** is the default and the recommendation.
The instance updates whenever a newer version is published to the fleet.

**Static** pins the instance.
It stays on the version you selected until you change it.
Use this when you need to hold a version for a validation window.

Switching from static to dynamic moves the instance to the current fleet version on the next pass.

## Upgrade manually

Upgrade a pinned instance by selecting a newer version on the card.
You can only move forward, so an upgrade never downgrades an instance.

The status badge shows **Upgrading** while the change rolls out, and returns to **Running** when it finishes.
