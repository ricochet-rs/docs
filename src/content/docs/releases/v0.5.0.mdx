**Released: April 2, 2026**

### Features

- Deployments now stream server-sent events (SSE), and content SSE works better.
- A new API endpoint returns content thumbnails.
- Users can now set an avatar from Gravatar/Libravatar, a custom upload, or OIDC picture sync.
- Each user now has a public profile page, and explore page cards look better.
- The restore process now gets the content's environment variables.

### Improvements

- The user profile page has a cleaner layout and design.
- The expanded sidebar is now narrower to save space.
- Task and app log panels now share one width.

### Fixes

- Ricochet no longer needs Quarto on `PATH`.
- Ricochet now finds Python installs that UV does not manage.
- Adding or deleting environment variables now stops all running instances.
- Deleting a Kubernetes deployment now removes it fully.
- A deployment with no packages file now returns a 400 error, and Ricochet checks the `.python-version` file.
