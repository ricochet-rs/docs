An instance is a ricochet server that ricochet Cloud runs for you.
Owners and admins create instances under **Instances**.

<Steps>

1. Select **Create instance**.

2. Enter a name.

3. Confirm the region.

    Instances currently run in `eu-west`.

4. Choose **Dynamic** or **Static** updates.

    See [Versions and Upgrades](/dev/cloud/instances/2-versions-and-upgrades/).

5. Create the instance.

</Steps>

Provisioning takes a few minutes.
Once the status is **Running**, **Open application** signs you in to the instance.

The instance answers at `https://<instance-name>-<organization-slug>.cloud.ricochet.rs`.
You can replace this address with a [custom domain](/dev/cloud/instances/3-custom-domains/).

Only the person who created the instance can open it at first.
Grant other members access under [Access](/dev/cloud/instances/4-instance-access/).

## Deploy to it

An instance works like any other ricochet server:

```bash
ricochet login -S https://<instance-name>-<organization-slug>.cloud.ricochet.rs
ricochet deploy
```

The [Usage](/dev/user/quickstart/) section applies from here on.
