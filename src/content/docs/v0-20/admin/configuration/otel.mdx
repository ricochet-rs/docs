---
title: OpenTelemetry
---

Ricochet can send traces to any [OpenTelemetry](https://opentelemetry.io/) (OTel) backend over the OpenTelemetry Protocol (OTLP).
[Jaeger](https://www.jaegertracing.io/) and [Grafana](https://grafana.com/) are two examples.

Ricochet shows up as the `ricochet-server` service and sends spans in async batches.

## Configuration

Add an `[otel]` section to `ricochet-config.toml`.
Set `endpoint` to the URL of your OTLP collector:

```toml
[otel]
endpoint = "http://localhost:4317"
```

## Example Jaeger setup

Jaeger is an open source OTLP collector that works with ricochet out of the box.

:::tip[Get the current Jaeger version]
Replace `<version>` with the version the [Jaeger getting started guide](https://www.jaegertracing.io/docs/latest/getting-started/) recommends.
:::

Start the Jaeger container:

```bash
docker run -d --name jaeger \
  -p 4317:4317 \
  -p 16686:16686 \
  cr.jaegertracing.io/jaegertracing/jaeger:<version>
```

Add the following to `ricochet-config.toml`:

```toml
[otel]
endpoint = "http://localhost:4317"
```

Start ricochet and open `http://localhost:16686` to see traces in the Jaeger UI.
