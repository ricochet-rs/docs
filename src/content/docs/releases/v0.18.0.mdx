**Released: August 23, 2026**

### Features

- Connect to PostgreSQL databases in addition to the existing database options.
- Community edition now enforces usage limits to ensure compliance with the license.

### Fixes

#### Authentication

- Signed-out visitors are returned to the original app link they opened after authenticating.

#### Permissions

- The deploy wizard server functions now correctly require the publish role before allowing deployments.

### API

- The Scalar API client picker is limited to four languages for a cleaner interface.
