Ricochet isolates each deployment from the one before it.
To keep files across deployments, or to share them between your app's workers, save them in the `./persistent` directory.

Ricochet puts `./persistent` at the root of your bundle in every deployment, and keeps what you save there until you delete the app or task.
Treat `./persistent` like any other folder:

<Tabs syncKey="language">
  <TabItem label="R">
    ```r
    # save a model, then read it back after a restart or redeploy
    saveRDS(model, "persistent/model.rds")
    model <- readRDS("persistent/model.rds")
    ```
  </TabItem>
  <TabItem label="Julia">
    ```julia
    using Serialization

    # save a model, then read it back after a restart or redeploy
    serialize("persistent/model.jls", model)
    model = deserialize("persistent/model.jls")
    ```
  </TabItem>
  <TabItem label="Python">
    ```python
    import pickle

    # save a model, then read it back after a restart or redeploy
    with open("persistent/model.pkl", "wb") as f:
        pickle.dump(model, f)
    with open("persistent/model.pkl", "rb") as f:
        model = pickle.load(f)
    ```
  </TabItem>
</Tabs>

## Ship Files With a Deployment

To start with data, put a `persistent/` folder in your bundle.
When you deploy, ricochet copies its files into `persistent/` and keeps any file already there with the same name.

## Package Cache

Ricochet installs each version of an R, Julia or Python package once, then reuses it for every app and task that needs it.
So you wait less on later deployments.
