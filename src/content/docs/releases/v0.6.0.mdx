**Released: April 8, 2026**

### Features

- Preflight checks now test dependencies before each operation and can restore them on their own.
- A bundle retention policy sets how long bundles stay in storage.
- Execution environments now work for Julia and Python.
- Containers now run as non-root users and accept the random UIDs that OpenShift assigns.
- One credentials page now holds both API keys and Git credentials.

### Features (Kubernetes)

- Ricochet now spots when a Kubernetes execution environment drifts from its set config.

### Fixes

- Startup now handles database migration state better and reports errors more clearly.
- Systemd setup no longer changes the whole Ricochet home folder, so installs run faster.
- Scripts now load as they should, and the UI no longer shows hydration warnings.
