**Released: June 1, 2026**

### Features

#### UI

- You can now search and filter the /apps, /tasks, and /deployments pages.
- REPL logs now have syntax colors and cleaner timestamps.
- Kubernetes container logs now use short timestamps.

#### Authentication

- You can now grant collaborator access to OIDC groups.

### Fixes

#### Proxy

- Local containers now stop on shutdown.
- Zombie processes are now reaped, so they no longer leak resources.

#### Kubernetes

- Spawned pods now set a securityContext for better security.

#### UI

- Delete dialogs now align well and no longer loop console errors.
- The deploy status checkmark now shows correctly.

#### General

- The launcher validator now gets the exec-env category instead of the resolved URL.
- The restore process now works the same on Linux and Kubernetes.
- Private content now shows up as it should.
- Changes to collaborator roles are now in the audit log.
