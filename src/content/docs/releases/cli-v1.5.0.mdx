**Released: November 18, 2026**

## New features

The CLI now includes a **ricochet mcp** subcommand that exposes Ricochet functionality to AI assistants through the Model Context Protocol.

The CLI now includes a **ricochet lsp** subcommand that provides real-time diagnostics for `_ricochet.toml` configuration files in editors that support the Language Server Protocol.

## Fixes

The **ricochet deploy** command now correctly validates Git repository URLs and accepts folder-style URLs.

The CLI now builds on Rust 1.100.
