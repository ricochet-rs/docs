**Released: June 10, 2026**

### Features

- The `init` subcommand now accepts a default content ID for easier setup
- New commands let you manage app instances:
  - `ricochet app instances {id}`: List instances for an app
  - `ricochet app stop-instance {id} {pid}`: Stop a specific app instance
- The CLI now supports deployment endpoints for more flexible deploy setups.
