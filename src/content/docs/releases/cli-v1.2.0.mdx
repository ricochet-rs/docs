**Released: September 10, 2026**

## New features

The `list` command now accepts an `--all` flag that displays every item on the instance for instance admins.

The `plumber2` and **_server.yml** standards for R projects are now supported.

A new `ricochet-cli` agent skill is available for AI-assisted workflows.

## Bug fixes

The `-F json` and `-F yaml` formatters now emit only the payload on `stdout` instead of including metadata.

The Windows installer now saves the binary as `ricochet.exe`` and adds it to the system `PATH`.
