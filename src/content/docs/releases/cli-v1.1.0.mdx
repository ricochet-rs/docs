**Released: August 14, 2026**

### Features

#### Deployments

- `ricochet deploy --git` deploys content from a Git repository.

#### Authentication

- `ricochet user credentials` manages authentication credentials.
- The first login defaults to the hosted trial.

#### Environment variables

- You can fetch, add, delete, update, and overwrite environment variables from the CLI.

### Fixes

#### Command output

- `ricochet invoke` and `ricochet settings update` produce valid JSON and YAML output.

#### Deployments

- Deployment bundles exclude Python `__pycache__` directories.
