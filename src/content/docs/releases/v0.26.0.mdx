**Released: November 17, 2026**

### Features

- Task and deployment logs now have the same search and layout features as app logs.
- App deployment logs appear in the **Logs** tab alongside runtime logs.
- Filter app log lines to show only entries matching your search criteria.
- Log entries from later invocations always appear in the correct order, superseding earlier entries.

- Browse deployment and persistent files for any item in the new **Files** tab.
- Ricochet retains the five most recent deployments per content item by default.

#### Authentication
- Entra groups and profile photos are now read using the signed-in user's token instead of a service account.

### Fixes

#### Deployment and runtime
- Improved rollout of deployment workers as to prevent disconnected user sessions
- FastAPI apps start correctly when the entrypoint is located in a subdirectory.
- R projects with an renv configuration that fails to load now fail during restore rather than at runtime.
- Docker and Podman deployments now run successfully from start to finish.
- Python content automatically deletes stale virtual environments to free up space.

- Fixed bug pertaining to content isolation
- Users with the Consumer role can no longer read runtime logs for apps they don't own.

- Email settings are hidden when no SMTP mail server is configured.
