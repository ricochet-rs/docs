**Released: April 23, 2026**

### Features

- A new environment page in the UI lets you view and manage environment settings in one place.
- You can now cancel running restore jobs in the UI.
- A new ricochet-server CLI subcommand lists users and sets user roles.
- A manual git sync button in the UI shows when the last sync ran.
- Package restores now send a custom HTTP user agent so they work with rpkgs.com binaries.

### Fixes

- The proxy now sets the `R_LIBS_USER` environment variable to match the restore process.
- The proxy now finds Shiny app entrypoints, since it passes `appDir` the right way.
- The proxy now uses the vendored renv from `R_LIBS_USER` instead of `requireNamespace`.
- Some small UI bugs are fixed.
- The TOML API endpoint no longer returns (encrypted) environment variables.

### Security

- The init process now handles SIGTERM as PID 1 and falls back to SIGKILL to stop zombie processes.
