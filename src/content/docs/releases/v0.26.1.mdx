**Released: November 18, 2026**

### Features

- Deployment failures now appear as alerts on both the app overview and task overview pages.

### Fixes

- R deployment logs now display cleanly without garbled output from `pak`.
- Log lines now use consistent labels across all backend types.

### Security

- The email library has been updated to address a security vulnerability.
- The compression library has been updated to address a security vulnerability.
