**Released: September 3, 2026**

### Features

- Administrators can now upload a custom favicon for the entire instance and manage it from a new sidebar section.

### Fixes

#### User Interface

- List views now display an indicator when a filter is active and provide a button to clear it.
- The authorization gate no longer incorrectly denies access during the initial resource loading phase.
- The audit log table now stays within its container boundaries, and the instance favicon description has been clarified.

#### Kubernetes

- Launcher resources are now properly isolated by instance to prevent cross-instance interference.
