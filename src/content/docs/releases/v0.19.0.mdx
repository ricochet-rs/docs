**Released: September 2, 2026**

### Features

#### Explore page
- Browse content in a list view with sortable columns and the ability to filter by tags.

#### Apps and tasks
- Copy the app URL directly from the overview page.
- Stop running tasks from the UI.
- View Prometheus metrics tracked across both apps and tasks in the proxy.

#### API and administration
- Instance admins can now list all content items using a new "read" scope.
- The Scalar API reference tab displays a custom title and branding.

#### Configuration and deployment
- Community edition pages display a powered-by indicator.

### Fixes

- Python execution environments now include the `uv` field and resolve correctly for Kubernetes images.
- Mobile layouts display content more consistently.
- The runtime selection process prefers compatible newer versions.
- Navigation quick links collapse properly and breadcrumbs no longer wrap unexpectedly.
