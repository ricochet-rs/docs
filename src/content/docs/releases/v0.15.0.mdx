**Released: July 22, 2026**

### Features

- Error toasts now stay on screen, can be copied, and have a resync action to help you recover.
- On the host backend, ricochet tracks memory use and tries to flag crashes caused by running out of memory.
- Ricochet now finds Quarto installs and shows them in the environment view.
  It always uses the newest Quarto version.
  A future release will let you pick a version.

### Fixes

- OIDC credentials can no longer be accessed, which fixes a critical security issue.
- Rerunning Quarto documents with Python no longer shows false out-of-sync warnings.
- A strict deny list now blocks access to files in the item's output directory that should not be served.
- Redirects from `/static/{id}` to `/static/{id}/` now work, so resources load as they should.
- The UI now hides interpreters when ricochet runs on Kubernetes.
- The **View** option now shows for rendered tasks without manual static content setup.
- Key objects now display correctly in the Scalar API docs.
